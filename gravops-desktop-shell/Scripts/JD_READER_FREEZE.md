# JD 商品读取冻结规则

这份规则用于保护已经验证可用的桌面端京东商品读取逻辑，后续修改 `jd-webview-reader.js` 时必须遵守。

## 主图

- 主图只能来自商品左侧预览/轮播区域，例如 `.image-carousel-track`、`#spec-list`、`#spec-n1`、`.preview`、`#preview`。
- 不允许从整页 `img`、评论区、店铺区、推荐区、右侧 SKU 规格区批量补主图。
- 不允许在已有主图时用 `performance.getEntriesByType('resource')` 或全局资源缓存追加主图。
- 资源兜底只能在主图数量为 0 时使用。

## 详情图

- 详情图只能来自商品详情区域，例如 `#graphic-content`、`#J-detail-content`、`#detail`、`.detail-content`、`.ssd-module-detail`。
- 不允许从全局资源缓存直接生成详情图，因为 WebView 会保留上一页资源，容易混入旧商品图片或京东图标。
- 必须过滤评论图、晒单图、头像、二维码、logo、icon、店铺/推荐/通用装饰图。
- 必须过滤小资源图。URL 中图片字节数小于 8000 的 `/img/jfs/` 图不能作为详情图。
- 详情图 DOM 尺寸应至少约 300x220，避免把被页面放大的小图标误当详情图。

## 验证样本

每次改动后至少用以下类型页面手动验证：

- 文具/办公用品：主图、详情图、参数、规格。
- 汽车用品或轮胎：参数区在规格参数卡片里的页面。
- 服饰/户外：多颜色、多尺码、多系列 SKU 页面。

验收标准：

- 主图不混入评论图、其它颜色 SKU 图、店铺 logo、推荐商品图。
- 详情图不混入京东图标、上一页残留图片、小图标、评论图片。
- 参数和 SKU 仍能正常保存到任务中心。
